Updated build of Ash's HUD for Last Epoch Season 5 (Unity 6000.4.8) and MelonLoader 0.7.3 Open-Beta. Press F3 in a zone to open the mod menu.

Changelog:
**New features:**
* 1000 Soul Ember Button
* 10 000 Memory Amber Button
* AOE Slider
* Reveal Dungeon Objectives | Enter Without Key (Still uses portal charms)
* Withstand The Elements gloves modifier selection
* Infinite Forging Potential in Crafting
* Deselect All Button in Crafting
* Renamed 2h with shield -> Ignore Weapon Restrictions (This will now allow you to equip any item combination e.g. 2h/off-hand, 2h/catalyst etc..)

**Fixes:**
* Safe Teleport
* Translated Force Drop Selectors
* Sands of Silk, Mjolner, HH, Essentia Sanguis are currently being reworked and will not work
* Locale fix for when you switch from a language back to EN

**Back-End stuff:**
* Releases will now unzip correctly on Linux
* GitHub Actions for PR tests
* CSharpier on all C# files
* .git-blame-ignore-revs so GitHub's blame view skips the format commit.
