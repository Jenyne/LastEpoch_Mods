# LastEpoch HUD v5.0.0

Updated build of Ash's HUD for Last Epoch Season 5 (Unity 6000.4.8) and MelonLoader 0.7.3 Open-Beta. Press F3 in a zone to open the mod menu.

## Changelog

### Features

* UI Has Been Fully Reworked!
* Force Drop Illegal Mode
* Prophecy Reward Multiplier (max 10x)
* Spawn 1m Gold Button
* No Transform Health Decay (no health drain from certain skills)
* Headhunter Fully Working And Fully Reworked

### Fixes

* Remove Secondary Mastery Lock (chain)
* Force Drop Affix Filtering Fixes
* Online play button has been fully disabled

## Install

- Install steps are in the repository [README](https://github.com/Syncingoutt/LastEpoch_Mods/blob/master/README.md).
- Alternatively, use the [LE Hud Installer](https://github.com/TriSSec-Lab/LE-Hud-Installer) to install the mod automatically.
